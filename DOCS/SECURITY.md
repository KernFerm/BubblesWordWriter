# Security Policy

This policy explains how to report a possible Bubbles Word Writer security problem safely and privately.

## Supported Versions

Security corrections are provided for the latest published Bubbles Word Writer release. Install the newest available version before reporting a problem that may already be fixed.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Report A Vulnerability Privately

Do not post security details in a public issue, discussion, pull request, or social-media message.

1. Open the [Bubbles Word Writer Security page](https://github.com/KernFerm/BubblesWordWriter/security).
2. Select **Report a vulnerability**.
3. Submit the report privately through GitHub.

If private reporting is unavailable, contact the repository owner privately through the [KernFerm GitHub profile](https://github.com/KernFerm). Do not publish technical details while trying to make contact.

## What To Include

- The affected Bubbles Word Writer version
- Your Windows version
- A clear description of the possible impact
- Steps needed to reproduce the problem
- Whether another person must interact with a file or message
- A small example made with non-sensitive test data
- Redacted screenshots or diagnostic messages, when useful

Never send real documents, passwords, access codes, private room names, personal information, or other confidential data.

## What Happens Next

The report will be reviewed privately. Additional non-sensitive information may be requested. Confirmed problems will be evaluated, corrected, tested, and disclosed when it is safe to do so.

The time needed depends on the severity and complexity of the issue. A submitted report may be closed if it is not reproducible, has no security impact, or affects only an unsupported version.

## Safe Reporting

Use only computers, accounts, documents, and services that you own or have permission to test. Do not access another person's information, disrupt a service, or perform destructive testing.

Stop testing if you encounter private user information and report the issue without copying that information.

## Installer Safety

Download Bubbles Word Writer only from the official [GitHub repository](https://github.com/KernFerm/BubblesWordWriter). The installer is intentionally unsigned, so Windows may display a SmartScreen warning.

The installer checksum for the current release is listed in [RELEASE.md](RELEASE.md). A checksum helps confirm that a downloaded file matches the published installer.

## Reporter Credit

People who responsibly report a confirmed vulnerability may request public credit after a correction is available. Requests to remain anonymous will be respected where possible.
