# Release History

This page summarizes changes that matter to people using Bubbles Word Writer. It intentionally leaves out internal development, security implementation, build-system, and testing details.

## 2.6.55

- Updated the application components used for editing, packaging, updates, file handling, testing, and Windows integration.
- Updated the editor family together to maintain document and formatting compatibility.
- Resolved newly reported dependency security advisories.
- Confirmed that the application builds cleanly and passes all current writing, command, and language checks.
- Retained the compatible equation-rendering version required by the current mathematics editor.

## 2.5.22

- Corrected the GitHub location used by the update checker.
- Replaced technical update errors with clear, end-user-friendly messages.
- Updated installation, release, privacy, security, and troubleshooting documentation.
- Expanded the supported-file table to show every accepted extension.

## 2.5.20

- Improved optional collaboration with viewer and editor access levels.
- Improved reconnection and local editing when a collaboration service is temporarily unavailable.
- Improved recovery, accessibility labels, and responsiveness with larger documents.
- Added safer controls for trusted local extensions.
- Improved Find, Replace, printing ranges, and document handling.

## 2.5.16

- Added a startup splash screen and Bubbles Word Writer branding.
- Added update checking with stable, beta, and developer choices.
- Expanded printing options, including page ranges, copies, duplex, scaling, and pages per sheet.
- Added higher-quality legacy Word import when LibreOffice is installed.
- Added an offline English dictionary and thesaurus.
- Expanded page layout, tables, headers, footers, and document-review tools.
- Added English, Spanish, and Arabic interface support.
- Added local image text recognition, dictation, and text-to-speech tools.
- Improved comments, citations, mail merge, labels, envelopes, and tracked changes.
- Added installer choices for keeping or removing settings, recovery information, extensions, and profile data.

## 1.0.42

- Added editable page boundaries, page counts, headers, footers, and page breaks in Print Layout.
- Added Web, Draft, Outline, Reading, and Focus views.
- Added right-to-left editing and mixed-language document support.
- Added customizable keyboard shortcuts, toolbar commands, and ribbon groups.
- Improved typing responsiveness, recovery, document inspection, and large-document handling.
- Expanded DOCX, ODT, RTF, HTML, Markdown, text, data, and programming-file support.
- Added comments, references, citations, bookmarks, indexes, and document comparison.
- Added optional local collaboration, local writing assistance, OCR, dictation, and speech.

## 0.1.0

- Introduced the Bubbles Word Writer desktop application.
- Added tabbed document editing, formatting, tables, images, menus, and keyboard shortcuts.
- Added local save, open, print, PDF export, recovery, version history, and templates.
- Added the Windows installer, file associations, privacy information, and end-user license agreement.
